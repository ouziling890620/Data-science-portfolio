# Data Analysis Projects

透過 Hahow 線上課程「資料分析的七個練習專案」自主學習的實作紀錄，
練習從原始資料清理、SQLite 資料庫建置到靜態與互動式資料視覺化。

## 專題列表

1. [兩百個國家、兩百年、四分鐘](./01-gapminder_clone) - 復刻 Hans Rosling 經典資料視覺化，
   呈現兩百年間各國人均GDP與預期壽命的動態變化<br>
   👉 [互動式瀏覽](https://ouziling890620.github.io/Data-science-portfolio/data-analysis/01-gapminder_clone/gapminder_clone.html)</br>
   （因包含完整動畫資料，檔案較大，首次載入可能需要數秒至十幾秒）

2. [拿破崙征俄戰爭](./02-minard_clone) - 復刻 Charles Minard 經典資料視覺化，
   在同一張圖呈現1812年拿破崙大軍的行軍路線、人數變化與氣溫下降<br>
   👉 [成品圖片](https://github.com/ouziling890620/Data-science-portfolio/blob/main/data-analysis/02-minard_clone/minard_clone.png)

3. [大疫世代](./03-covid_19_pandemic) - 使用CSSE at Johns Hopkins資料，
   建立含地理地圖與時間序列的Covid-19疫情儀表板<br>
   👉 [線上互動瀏覽（Hugging Face Spaces部署）](https://huggingface.co/spaces/ouziling890620/covid_19)</br>
   （部署於免費方案，偶爾可能因服務不穩定而未能正常顯示，重新整理頁面通常可解決。）
